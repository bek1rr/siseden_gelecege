# Şişeden Geleceğe — ücretsiz proje sitesi

## GitHub Pages ile yayınlama
1. GitHub hesabınızla `siseden-gelecege` adlı **Public** depo oluşturun.
2. Bu klasördeki `index.html` ve `data.js` dosyalarını deponun ana dizinine yükleyin.
3. Repository > Settings > Pages > Build and deployment: Deploy from a branch > Branch: `main`, Folder: `/(root)` > Save.
4. GitHub Pages'in verdiği adresi açıp test edin. Genellikle `https://KULLANICIADI.github.io/siseden-gelecege/` şeklindedir.
5. QR kodu ancak gerçek site açıldıktan sonra bu adresten üretin.

## İstatistik güncelleme
`data.js` dosyasını GitHub üzerinde açın > kalem simgesi (Edit) > `basladi: true` ve gerçek `toplanan`, `iadeEdilen`, `fonTL` değerlerini yazın > Commit changes. Site güncellendiğinde yeni rakamlar görünür.

**Önemli:** Şişe başına 1 TL bilgisini ve otomatın kapaklı/kapaksız ambalaj kabulünü yerinde doğrulayın. Otomatın reddettiği şişeleri 'iade edilen' sayısına katmayın. Kişisel bilgi yayınlamayın.
